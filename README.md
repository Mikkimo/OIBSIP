# Number Guessing Game

## Objective

A simple Java console-based game where the computer generates a random number between 1 and 100, and the user tries to guess it.

## Technologies Used

* Java
* Scanner
* Random
* Eclipse IDE

## Features

* Generates a random number from 1 to 100
* Accepts user guesses
* Displays "Too High" or "Too Low" hints
* Counts the number of attempts
* Handles invalid input

## How to Run

1. Open the project in Eclipse.
2. Open `NumberGuessingGame.java`.
3. Right-click the file.
4. Select **Run As → Java Application**.
5. Enter your guesses in the Console.
